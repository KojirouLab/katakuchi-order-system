# 社内タスク管理アプリ セットアップ手順

発注システムと同じSupabaseプロジェクト・同じGitHub Pagesをそのまま使います。
追加で必要なのは次の2つだけです。

## 1. Supabaseにテーブルを追加する

1. 発注システムで使っているSupabaseプロジェクトを開く
2. 左メニューの **SQL Editor** を開き、このフォルダの `supabase.sql` の中身を貼り付けて実行
   (`task_employees` / `task_items` / `task_logs` という新しいテーブルができます。発注システムの
   テーブルには影響しません)

これで `管理者` という名前・PIN `0000` の管理者アカウントが1つ作られます。

## 2. 社員を登録する

SQL Editor で、社員の人数分だけ次の文を実行してください(名前とPINは自由に決められます)。

```sql
insert into task_employees (name, pin_hash, is_admin) values
  ('田中', crypt('1234', gen_salt('bf')), false);
```

- 管理者にしたい人は `false` の部分を `true` にしてください(全員のタスクが見られるようになります)。
- PINは4桁の数字がおすすめですが、何桁でも構いません。
- 最初に作られた `管理者` / PIN `0000` は、本番運用の前に上のSQLと同じ要領で `update` して
  名前や PIN を変えておくか、使わないなら以下で削除してください。

```sql
-- 例: 管理者アカウントの名前とPINを変更する
update task_employees set name = '山田', pin_hash = crypt('5678', gen_salt('bf')) where name = '管理者';

-- 例: サンプルの管理者アカウントを削除する
delete from task_employees where name = '管理者';
```

退職者を削除したいときも `delete from task_employees where name = '氏名';` で削除できます
(過去に依頼・担当したタスクの記録は残ります)。

## 3. アプリを開く

発注システムと同じGitHub Pagesの中に `tasks/` フォルダとして公開されるので、追加設定は不要です。

```
https://ユーザー名.github.io/リポジトリ名/tasks/
```

このURLを社員に共有し、ホーム画面に追加してもらうと次回から一発で開けます。

## 4. 使い方

- ログイン: 名前を選んでPINを入力
- 「自分のタスク」: 自分が担当のタスク一覧。「着手する」→「完了として報告する」の順にステータスを進めます
- 「依頼したタスク」: 自分が他の人に頼んだタスクの進捗確認
- 「みんなのタスク」(管理者のみ): 全員分のタスクを担当者・ステータスで絞り込んで確認
- 右下の「＋ 新しいタスクを依頼」から誰にでもタスクを依頼できます
- タスクをタップすると詳細画面が開き、コメントや完了報告の履歴が確認できます

## 5. 運用上の注意

- PINによる簡易的な本人確認のみで、パスワードの強度チェックなどはありません。他人に推測され
  にくいPINを使ってください。
- PINを忘れた場合は、管理者がSupabaseのSQL Editorから上記の `update` 文でリセットしてください。
- 「みんなのタスク」タブは `is_admin = true` の社員だけに表示されます。
